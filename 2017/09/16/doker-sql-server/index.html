Docker化的mssql-server

2017年9月16日

本来上数据库的课需要安装mssql-server，但是通过Docker，不需要在实体机上安装一堆mssql或者虚拟机，相对而言更加优雅。

Docker是比虚拟机小的虚拟化容器技术，每个Docker镜像都有一个基本的特定的功能，比如配置好PHP环境的镜像、数据库系统。

在windows上Docker是运行在hyper-v上的，所以家庭版没有hyper-v是无法使用的，或者使用跑在virtualbox上的版本。
