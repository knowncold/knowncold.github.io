### 安装
	sudo apt install ruby-full  
	sudo gem install jekyll  

>在低版本的Ubuntu上可能会出现ruby版本过低的情况

	sudo apt-get install jekyll  

>现在好像能直接安装了= =

#### 安装插件

	sudo gem install jekyll-paginate


### 使用

	cd blog
	jekyll serve

### Mac OS安装

	brew install ruby
	sudo gem install jekyll
