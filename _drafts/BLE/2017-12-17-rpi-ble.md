> 树莓派上的蓝牙的BLE

## 

```
$ hciconfig
hci0:	Type: Primary  Bus: UART
	BD Address: **:**:**:**:**:**  ACL MTU: 1021:8  SCO MTU: 64:1
	UP RUNNING
	RX bytes:822 acl:0 sco:0 events:57 errors:0
	TX bytes:4231 acl:0 sco:0 commands:57 errors:0hciconfig
```

如果这个蓝牙接口是`DOWN`，通过下面的命令来启用：

```
sudo hciconfig hci0 up
```

## 扫描并连接

```
sudo hcitool lescan
```
