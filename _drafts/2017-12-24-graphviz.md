## 语法

### 图的横竖方向

```dot
digraph g {
    rankdir="LR";
    {
        rank="same";
        a0 -> a1 -> a2;
    }
    {
		rank="same";
        b0 -> b1 -> b2;
    }
    a1 -> b1;
}
```

## 输出格式
包括`gif`, `png`, `pdf`, `jpg`, `svg`, `bmp`

以`gif`为例

```bash
dot -Tgif test.dot -o test.gif
```
