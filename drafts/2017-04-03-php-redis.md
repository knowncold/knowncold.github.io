#### Installation

	$ sudo apt-get install redis-server php-redis

> 安装之后可能需要重启

#### 查看是否启动

	$ redis-cli
	127.0.0.1:6379> ping

	PONG

#### PHP连接

```php
	$redis = new Redis();
	$redis->connect('127.0.0.1',6379);
	$redis->set('name','value');
	$redis->expire('name',seconds);
```
